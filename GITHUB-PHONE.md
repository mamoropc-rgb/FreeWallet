# Доставка Android APK без компьютера

Рекомендуемый путь: загрузите `Karman-1.0.2-PremiumGlass-source.zip` в ChatGPT Work (виртуальный браузер), откройте репозиторий `Mamoro2142/CarmanBridg` и передайте инструкции `WORK-DEPLOY.md`.

Полный исходный код должен быть сохранён обычными файлами, а не одной нераспакованной ZIP-заглушкой. Workflow `.github/workflows/android.yml` собирает APK из файлов в репозитории и не применяет патчи к исходникам во время CI.

Если работа ведётся исключительно через мобильный веб-интерфейс GitHub, загружайте распакованное дерево, включая скрытую папку `.github/workflows`. В разделе **Actions** запускайте `Karman Android — verified build and signed update`.

Секреты подписи необходимо настроить отдельно по `SIGNING-SETUP.md`. Приватный ключ не входит в ZIP исходников. Без секретов Release не должен считаться готовым.
