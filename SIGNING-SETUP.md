# Подпись стабильных обновлений Karman

Приложение использует прежний `applicationId`: `com.mamoro.karman`. Версия исходников: 1.0.6, `versionCode = 7`.

## Главное правило

Не выпускать релиз новым случайным ключом. Приватный ключ уже создан ранее и хранится **отдельно** от публичного GitHub-репозитория в пользовательском архиве `Karman-PRIVATE-signing.zip`. В комплект исходников он намеренно **не включён**.

Проверенный сертификат: alias `karman-release`, SHA-256:

`72:31:6D:B9:E7:14:02:D3:D8:81:8B:E2:F7:29:75:97:F0:8A:64:3E:B7:DD:7D:1E:1E:BF:DD:E0:DE:EB:B2:A8`

Срок действия: до 2 ноября 2056 года. Workflow сверяет хэш сертификата до сборки и сертификат в готовом APK после сборки.

## GitHub Secrets

GitHub → Settings → Secrets and variables → Actions → New repository secret.

Скопируйте значения из **своего** `Karman-PRIVATE-signing.zip` / `GITHUB-SECRETS.txt`. Параметры в сохранённом комплекте называются:

- `KARMAN_KEYSTORE_B64` — base64-контент исходного `.p12`. Workflow также понимает имя `KARMAN_KEYSTORE_BASE64`.
- `KARMAN_KEYSTORE_PASSWORD` — пароль хранилища. Workflow также понимает `KARMAN_STORE_PASSWORD`.
- `KARMAN_KEY_PASSWORD` — пароль ключа.
- `KARMAN_KEY_ALIAS` — `karman-release`.

**Не публикуйте значения секретов**, содержимое `.p12`, исходный ZIP с приватными данными, пароли или копии в исходном коде. Не прикладывайте их к pull request, Actions Artifact или логу.

## Сборка

После установки секретов: Actions → `Karman Android — verified build and signed update` → Run workflow (ветка `main`). Только скачанный из `Karman-1.0.6-RELEASE-signed` файл `app-release.apk` должен использоваться как обновление.

Если секретов нет, релиз завершается ошибкой (но debug APK и отчёты тестов остаются доступными). Это намеренно: зелёная галочка не должна скрывать отсутствие подписанного APK.

Важно: если на телефоне установлена *debug*-версия (подписана другим сертификатом), Android не разрешит установить поверх неё *release* APK без удаления debug-приложения. Перед удалением экспортируйте резервную копию данных. **Не удаляйте** исходный кошелёк и не утверждайте, что сертификаты разных приложений взаимозаменяемы.
