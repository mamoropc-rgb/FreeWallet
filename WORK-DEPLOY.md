# Развёртывание в ChatGPT Work через виртуальный браузер

1. Откройте ChatGPT Work и передайте ZIP **Karman-1.0.2-PremiumGlass-source.zip**. Попросите создать отдельную ветку `feature/karman-premiumglass-102` в `Mamoro2142/CarmanBridg`. Сначала создавайте ветку/коммиты, не перезаписывайте `main` без проверки.
2. Замените содержимое проекта полным извлечённым деревом ZIP с сохранением `.github/workflows/android.yml`. `Karman-PRIVATE-signing.zip` **не загружать** и не прикладывать к PR.
3. Проверьте `applicationId=com.mamoro.karman`, `versionCode=3`, `versionName=1.0.2` и отличия кода. Отдельно зафиксируйте (Git commit) новую логику «До дохода», оформление Premium Glass и workflow подписи; если одно изменение ещё не проверено, не объединяйте его с другими.
4. Дайте GitHub Actions выполнить `testDebugUnitTest`, `lintDebug`, `assembleDebug`. Проверьте, что был создан **Debug APK**.
5. Через GitHub Settings → Secrets and variables → Actions установите 4 секрета из своего отдельного архива подписи, **только локально в закрытом интерфейсе**; убедитесь, что никакие значения не печатаются в логах и не попадают в исходники. Уже имеющиеся секреты не заменять без необходимости.
6. Запустите workflow `Karman Android — verified build and signed update` в ветке `main` (после проверки и принятия PR). Дождитесь зелёного статуса, артефакта `Karman-1.0.2-RELEASE-signed`, успешных `apksigner verify` и сертификата SHA-256.
7. Перед установкой на телефон экспортируйте резервную копию данных. Если ранее был установлен Debug APK, подписи Debug/Release не совпадают и обновление поверх Debug не установится.
8. Не утверждайте «готово к установке» до появления реально подписанного Release APK.

**Примечание:** текущий GitHub-коннектор в чате способен читать код, но создание ветки получило HTTP 403. Поэтому загрузка и GitHub Actions должны выполняться через Work с доступом на запись или после повторного подключения GitHub.
