# Premium Glass: сохранённые требования

- Две основные темы: `DARK` и `LIGHT`, плюс режим `SYSTEM`.
- Цветовая палитра: сине-графитовый фон `#080C1C` / светло-лавандовый фон `#F0EEFF`, акцент фиолетовый `#8C4DFF`, светлый акцент `#A773FF`.
- Три режима графики: `MAX`, `BALANCED`, `FAST`. Они не меняют бухгалтерскую логику, расположение вкладок и значение сумм.
- Фоновые градиенты, декоративные банковские карты, мягкие тени, закруглённые glass-карточки; в режиме `FAST` градиенты тяжёлых карточек заменены статической заливкой. Режим переключается в «Ещё» без перезапуска.
- Целевой экран: 6,55 дюйма AMOLED, FHD+ 1080×2400, соотношение 20:9. Макеты Compose адаптивны по ширине в dp, не привязаны к пиксельным координатам.
- Главное: баланс (переключение отображаемой валюты), «До дохода» (дата, доступный остаток, дневной лимит, будущие платежи и защищённые резервы), быстрые действия «Доход», «Расход», «Перевод», «Счета», цель, последние операции, итог месяца.
- Данные доступны офлайн. Переключение темы не меняет денежные операции и не очищает базу.
- Цель — соответствие эталонному рендеру, а не обещание безусловного попиксельного совпадения. Фактическое визуальное сравнение потребует собранного APK и скриншотов устройства.

## Производительность

- Логика «До дохода» использует один проход по операциям (кроме предварительного построения индекса уже проведённых операций), ожидаемая сложность O(accounts + entries + plans × occurrences).
- Статические декоративные элементы не влияют на расчёт, режим `FAST` отключает сложные градиенты карточек и декоративные карты.
- При возвращении приложения из фона дата обновляется, чтобы дневной лимит не застывал после полуночи.
- Курсы и виджет баланса не меняют исторические рублёвые суммы.
