# Категории и теги — 1.0.7

Реализация: Kotlin/Compose, SQLite, без интернет-аккаунтов и синхронизации.

## Пользовательские сценарии

- `Ещё → Категории и теги`: выберите «Категории» или «Теги», затем добавьте, измените или удалите элемент.
- Для категории выбираются тип доход/расход, название (1–60 символов), один из 10 цветов и 8 начальных иконок. У существующей категории тип не меняется.
- Для тега выбираются название и цвет. Имена уникальны без учета регистра.
- `Новая операция`: доступны категории соответствующего типа, создание категории/тега без выхода из операции, выбор до 12 тегов.
- `История → Операции`: можно искать операции по тегам, фильтровать по тегу и менять назначенные теги при редактировании операции.

## Сохранность

- При переименовании категории ее имя атомарно меняется в таблицах `entries`, `templates` и, для расходов, `budgets`. Суммы не меняются.
- Удаление категории удаляет ее из справочника, оставляя исторические записи с прежним названием.
- При переименовании тега его связи с операциями сохраняются. Удаление тега удаляет только связи, не операции.
- При удалении операции SQLite удаляет её связи с тегами автоматически через внешний ключ.
- Миграция `karman_v1.db` из версии 1 или 2 в версию 3 сохраняет существующие счета, операции, инвестиции и подписки.
- Экспорт JSON содержит три новые таблицы: `categories`, `tags`, `entry_tags`. Ранее созданные JSON-копии без этих таблиц можно импортировать; стандартные категории будут восстановлены.

## Ограничения текущей версии

- Встроено 8 стартовых иконок и 10 цветов.
- Теги пока не используются для отдельного графика аналитики; фильтр доступен в истории операций.
- Теги автоматически не назначаются банковским уведомлениям: новые операции можно отредактировать после импорта. Кешбэк не используется.
