# Субсчета внутри банка — 1.0.5

## Сценарий

`БеларусьБанк` → основной остаток `19,69 Br` + карта `2018` `50,00 Br` = общий остаток `69,69 Br`.

Банк — виртуальная группа. Денежные счета остаются независимыми; общая сумма не дублируется в главном балансе. В карточке представлены название банка, текущий общий остаток, сумма начальных остатков, курс из «Ещё», список субсчетов с их текущими остатками и кнопка добавления.

## Настройка существующих счетов

1. Откройте «Счета» → «Изменить» у имеющегося счета, укажите банк и последние 4 цифры карты.
2. Чтобы добавить вторую карту, используйте кнопку «Добавить карту / субсчёт» внутри карточки банка.
3. Задайте название и начальный остаток для каждого **отдельного** счета. Не копируйте общий баланс банка как остаток каждого субсчета.
4. Если счета привязаны к операциям/инвестициям, нельзя менять валюту и старый начальный остаток, но можно изменить банк, название и последние 4 цифры.

## Мультивалютность

Группировка выполнена по банку и валюте. Счета BYN и RUB не складываются численно. Для каждого валютного набора создается отдельная карточка; конвертация новых операций выполняется по курсу из «Ещё».

## Автоматический импорт Т-Банка

- Только рублевые субсчета `Т-Банк`.
- Если последние четыре цифры карты совпали с одним субсчетом, туда заносится покупка.
- Если последняя четверка неизвестна или скрыта при наличии нескольких счетов — запись пропускается. Нельзя произвольно списывать с первой карты.
- Дубликаты уведомлений блокируются, кешбэк никогда не учитывается.

## Сохранность

Миграция SQLite `1 → 2` добавляет только `bank_group` и `card_last4` к существующей таблице `accounts`. Другие таблицы и записи не изменяются. Старые JSON-копии совместимы благодаря значениям по умолчанию для новых полей.
