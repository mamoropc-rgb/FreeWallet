# Импорт покупок из уведомлений — 1.0.4

1. Откройте **Ещё → Автоматический учёт покупок**.
2. Выберите рублёвый банковский счёт, соответствующий карте Т-Банка.
3. Нажмите **Настроить доступ к уведомлениям** и разрешите «Карману» доступ на системном экране Android.
4. Вернитесь в приложение и включите **Автоматический учёт покупок**.
5. Новые уведомления Т-Банка со строками вида `Магнит Покупка на 610,96 ₽` будут записаны отдельными расходами.

Из уведомления извлекаются **только название магазина и сумма покупки**. Остальные начисления и реквизиты игнорируются, не сохраняются в кошельке и не учитываются в доходах. Для одного сгруппированного сообщения поддерживаются несколько строк покупок. Неоднозначные форматы и другие банки не импортируются.

Защита от повторной записи: одинаковая покупка того же магазина на ту же сумму в пределах **10 минут** считается повтором; если действительно было две одинаковых покупки за этот период, вторую нужно внести вручную. Удаление ранее импортированной операции из истории может позволить повторный импорт при повторной доставке уведомления.

**Примечание:** Android даёт приложению доступ к системной ленте уведомлений целиком; текущая реализация обрабатывает только уведомления пакета `com.idamob.tinkoff.android`. Ничего не отправляется на сервер. Доступ можно отозвать в Android, функцию можно выключить в настройках «Кармана». Уже показанные уведомления автоматически не импортируются.

При обновлении с 1.0.3 не очищайте данные. Подпись Release APK должна быть оригинальной; `applicationId` не меняется. Секреты остаются только в настройках GitHub Actions.
