# «До дохода» — расчёт и правила

Новая отдельная карточка на главной сразу под общим балансом. Дата поступления дохода выбирается через стандартный календарь и хранится локально в `preferences` как `nextIncomeDate=YYYY-MM-DD`. При отсутствии или истечении даты показывается предложение выбрать будущую дату. Сумма ожидаемого дохода **не** зачисляется заранее.

**Доход через N дней:** `N = DAYS_BETWEEN(сегодня, дата_дохода)`.

**Остаток до дохода:** текущий денежный баланс **включённых счетов** минус защищённые суммы целей и резервов минус непроведённые плановые платежи до даты следующего дохода плюс часть платежей, уже покрытая защищённым резервом. Плановые записи, уже проведённые в историях, исключаются по уникальному `source_key`. Запланированные платежи в день ожидаемого дохода не вычитаются. Плановые повторения (неделя/месяц) раскрываются только в пределах до даты дохода. Доходы будущего периода не начисляются авансом.

**В день:** `max(0, остаток) / N` с округлением вниз до копеек, отрицательная сумма отображается отдельным дефицитом. Валютные планы пересчитываются в рублёвый эквивалент по сохранённым для счёта справочным курсам. Дата должна быть позже текущей, не более чем через два года.

Примечания: логика сохраняет бухгалтерские правила действующего «Кармана», не меняет `applicationId`, DB schema и ключ подписи. Если резерв одного и того же планового платежа пересекается с резервом цели, пользователь может задать `coveredPlansMinor` в «Ещё», существующая настройка будет учтена. В нынешнем проекте нет отдельной сущности будущего дохода: дата вводится вручную.

Отображаемая валюта синхронизируется с чипами валют общего баланса; все вычисления остаются в RUB и не меняют историю.
