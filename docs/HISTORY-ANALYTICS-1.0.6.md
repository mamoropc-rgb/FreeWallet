# История и аналитика · 1.0.6

## Размещение
Внизу приложения остается прежняя вкладка **История**. В ней общие фильтры **месяца** и **счетов/групп банка**, а ниже переключатель **Операции | Аналитика**. Переключение не создает новых экранов или пересоздания базы. Режим «Операции» сохраняет поиск, фильтр доходов/расходов, выбор категории и существующее редактирование/удаление. Режим «Аналитика» содержит обзор, динамику расходов, рейтинги и сравнение со средними значениями. На экране аналитики кнопка «+» скрыта, чтобы не закрывать графики; на экране операций она остается.

## Расчеты
- Основная валюта — RUB. Используются исторические `Entry.baseMinor` (копейки) из сохраненных операций, а не пересчет по сегодняшнему курсу.
- **Расходы**: `Kind.EXPENSE`, **доходы**: `Kind.INCOME`. `Kind.TRANSFER` между своими счетами не включается в доходы и расходы. Сделки с инвестициями (`BUY`, `SELL`) и купоны (`COUPON`) тоже не смешиваются с обычными расходами и доходами.
- **Остаток от дохода за месяц** = доходы минус расходы выбранного месяца. Это не прогноз «До дохода» и не текущий баланс.
- **Денег всего** = текущий баланс включенных счетов; при выборе конкретного счета показывается текущий баланс этого счета.
- Для текущего месяца сравниваются расходы только до сегодняшнего числа включительно. Для прошедшего — весь выбранный месяц.
- Средние значения — по максимум трем **предыдущим месяцам с операциями**, строго по такому же числу месяца (с учетом коротких месяцев). Если предыдущих месяцев с данными нет — вывод «Нет сравнения», без искусственных цифр.
- График: линия накопленных расходов за текущий выбранный месяц, пунктирная средняя из предыдущих месяцев (при наличии).
- **Больше всего тратите**: рейтинг названий категорий расходов. **Чаще всего повторяются**: рейтинг магазинов/названий операций; импортированные магазинные покупки сохраняют исходные названия продавцов.
- Категории выше/ниже среднего сравниваются на основании тех же предыдущих месяцев. Нулевые месяцы без записей не включаются в среднее.
- Даты с некорректным форматом не должны аварийно закрывать аналитику.

## Приватность и ограничения
Новые разрешения Android не требуются. Текст банковских уведомлений дополнительно не считывается. Новые начисления/бонусы из уведомлений не используются; автоматическое отражение таких сумм не добавляется. Никаких синтетических операций в базе не создается.

В версии 1.0.6 для уже импортированных покупок название магазина может быть сохранено в поле категории. Поэтому в рейтинге категорий оно может отображаться как название магазина — это реальные сохраненные данные, не придуманная классификация. Расширенный справочник магазинов/категорий можно добавить отдельно.
