# Обновление FreeWallet до 1.0.7 со смартфона

1. Выполните экспорт данных в разделе «Ещё» → резервная копия до установки нового APK. Не удаляйте приложение.
2. Распакуйте `FreeWallet-1.0.7-changed-files.zip`. Загрузите все файлы с сохранением папок в существующий репозиторий `mamoropc-rgb/FreeWallet`, ветка `main`, заменив прежние файлы с совпадающими путями.
3. Новые файлы `CategoryTagRules.kt` и `CategoryTagUi.kt` поместите в `app/src/main/java/com/mamoro/karman/`, два новых теста — в `app/src/test/java/com/mamoro/karman/`.
4. Загружайте изменения из одного ZIP одной согласованной версией: частичная загрузка может сломать компиляцию до завершения.
5. GitHub → Actions → Karman Android — verified build and signed update. Дождитесь зеленой галочки.
6. В Artifacts скачайте **`Karman-1.0.7-RELEASE-signed`**, извлеките `app-release.apk` и установите поверх 1.0.6. **Не устанавливайте Debug APK.**
7. Проверьте создание категории и тега, запись операции с двумя тегами, фильтрацию истории по тегу, переименование категории, восстановление JSON-копии.

**Важное:** `versionCode = 8`; `applicationId = com.mamoro.karman`. Секреты `ANDROID_*` остаются в GitHub Actions. Приватный файл `.p12` НЕ включен ни в один архив. Новый ключ генерировать нельзя.

Полная Android-компиляция этой версии в этом чате не выполнялась.
