# Кошелёк · Karman Premium Glass 1.0.2

**Android 8.0+ · Kotlin 2.0.21 · Jetpack Compose · Android SDK 35 · package `com.mamoro.karman`**

Это полное дерево исходников версии 1.0.2 с двумя темами, тремя режимами графики, карточкой «До дохода» и прежними функциями учёта. База данных сохраняет прежнее имя и схему. Цифровая подпись только оригинальным сертификатом `karman-release`, SHA-256 указан в `SIGNING-SETUP.md`.

Релиз собирается в GitHub Actions (`.github/workflows/android.yml`), а не локальным Android Studio. GitHub Actions запускался успешно для прежней версии 1.0.1 (Debug), но **для этих исходников 1.0.2 ещё не запускался**. Сборка APK и работа на реальном Android не подтверждены. 

- `docs/UNTIL-INCOME.md` — формула и правила «До дохода».
- `docs/PREMIUM-GLASS.md` — темы, визуальный стиль, оптимизация.
- `SIGNING-SETUP.md` — инструкция для постоянной безопасной подписи; приватные ключи в исходники **не включены**.
- `WORK-DEPLOY.md` — процесс загрузки в GitHub через Work и проверки релизного APK.

## Сборка

В GitHub Actions при push и PR собирается Debug с `testDebugUnitTest`, `lintDebug`, `assembleDebug`. На `main` и при ручном запуске workflow дополнительно требует приватную подпись, а если секреты отсутствуют — сообщает ошибку вместо создания ложного успешного релиза.

**Сохранение данных:** до переустановки и особенно при смене Debug → Release выполните экспорт резервной JSON-копии. При смене подписи Android не сможет установить новое приложение поверх старого с тем же package ID.
