# Обновление FreeWallet 1.0.5 с телефона

1. Сделайте резервную копию в приложении «Ещё» → экспорт.
2. Распакуйте архив `FreeWallet-1.0.5-changed-files.zip`.
3. Загрузите в репозиторий `mamoropc-rgb/FreeWallet` файлы **с сохранением внутренних путей**. Существующие замените, новые создайте. Обязательно загрузите `.github/workflows/android.yml`, `app/build.gradle.kts`, новые `BankSubaccounts.kt` и `LedgerDbMigrationTest.kt`.
4. Нажмите `Commit changes` в ветку `main`, проверьте GitHub Actions → `Karman Android — verified build and signed update`.
5. При зеленом результате скачайте артефакт `Karman-1.0.5-RELEASE-signed` (ZIP), извлеките `app-release.apk` и установите **поверх** версии 1.0.4.
6. **Не устанавливайте** `DEBUG-test-only`: у него другая подпись. Не удаляйте приложение и не очищайте данные.
7. В «Счета» откройте счет → «Изменить», укажите банк (`Т-Банк`), название карты и последние 4 цифры. После этого используйте «Добавить карту / субсчёт» внутри карточки банка.
8. Проверьте, что суммы двух субсчетов дают итог банка, а перевод между ними не меняет общую сумму.
9. Для автоматического учета покупок откройте «Ещё» → импорт уведомлений и убедитесь, что доступ разрешен. Тестируйте с безопасно выбранными контрольными данными, не расходуя реальные деньги ради теста.

## Важно

- Существующая схема базы меняется миграцией без очистки данных, но перед установкой всё равно рекомендуется экспорт.
- Секреты цифровой подписи остаются в GitHub Secrets; архив исходников их не содержит.
- Локальные расчеты проверены, но **полная Android-сборка 1.0.5 ещё не выполнялась**. Если Actions выдаст ошибку, пришлите лог, чтобы исправить её до установки.
