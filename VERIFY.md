# Проверка Karman 1.0.2

## Выполнено локально

- Kotlin/JVM компиляция и запуск 7 проверок бухгалтерского расчёта «До дохода» без Android SDK.
- Сертификат `karman-release` из отдельного пользовательского архива успешно проверен `keytool`, сравнен с base64-представлением и зафиксирован fingerprint SHA-256 в workflow.
- Скрипты оформления и workflow проверены статически, синтаксис YAML распарсен.
- Исходный ZIP не должен содержать приватных материалов подписи.

## Требует GitHub Actions

- `:app:testDebugUnitTest` (включая Room/SQLite через Robolectric и тест новых настроек).
- `:app:lintDebug`.
- `:app:assembleDebug`.
- `:app:assembleRelease` **с тем же сертификатом**, проверки `apksigner` и публикация Release APK.
- Установка/интерактивные сценарии на Android, включая AMOLED 1080×2400, переключение тем и графики, экспорт/импорт, обновление по подписи, производительность и отображение макета.

Статус **не означает**, что APK 1.0.2 уже собран.
