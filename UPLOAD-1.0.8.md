# «Кошелёк» 1.0.8 — как обновить с телефона

Изменения: 323 ключа значков в 12 группах, поиск, сетка с ленивой отрисовкой, 36 пресетов и ручной RGB-цвет для категорий и тегов (HEX, HSV).

## Перед загрузкой

1. Откройте приложение → «Ещё» → экспорт резервной копии; сохраните JSON вне папки приложения.
2. **Не удаляйте установленное приложение.** Удаление может стереть локальную базу.
3. По состоянию на проверку репозиторий `mamoropc-rgb/FreeWallet` находится на **1.0.6**. Для него скачайте **`FreeWallet-1.0.6-to-1.0.8-cumulative-update.zip`**. Этот архив содержит и категории/теги 1.0.7, и расширение 1.0.8. Если в GitHub уже загружена полная 1.0.7, можно использовать меньший архив `FreeWallet-1.0.8-colors-icons-update.zip`. Распакуйте выбранный архив на телефоне.

## GitHub

4. В репозитории `mamoropc-rgb/FreeWallet` ветки `main` загрузите содержимое выбранного ZIP с сохранением **путей внутри архива**, замените одноимённые файлы.
5. Убедитесь, что новый файл `WalletIconCatalog.kt` находится строго в `app/src/main/java/com/mamoro/karman/`.
6. Файлы `app/build.gradle.kts` и `.github/workflows/android.yml` также должны быть обновлены, иначе проверка версии в CI завершится ошибкой.
7. Запустите GitHub → Actions → **Karman Android — verified build and signed update** → Run workflow, либо дождитесь запуска после push.
8. В случае зелёной галочки скачайте артефакт **`Karman-1.0.8-RELEASE-signed`**, откройте его ZIP и установите `app-release.apk` поверх установленной версии. **Не устанавливайте Debug APK.**

## Проверка

9. «Ещё» → «Категории и теги»: откройте редактирование категории, вкладку **Значок**, проверьте поиск «кофе», фильтр группы, выбор и сохранение. Проверьте цвет `#37A8D5` и изменение насыщенности; проверьте цвет тега.
10. Выполните тестовую операцию с новой категорией и тегом. Проверьте отображение значка в истории, фильтрацию, аналитику, экспорт и импорт JSON.

## Совместимость и подпись

- `applicationId` не менялся: `com.mamoro.karman`.
- `versionCode = 9`; `versionName = 1.0.8`.
- Схема SQLite осталась **3**: новая миграция не нужна, ранее созданные категории и теги сохраняются.
- Сертификат подписи остаётся прежним; `ANDROID_*` secrets не меняются. Файл ключа и пароли не включены в ZIP.
- Для Android 8.0+.

**Статус:** локальные проверки правил цветов, уникальности ключей, валидации базы и структуры архива прошли. Полная Android-сборка и проверка интерфейса должны пройти в GitHub Actions / на телефоне.
